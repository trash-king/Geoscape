-- Simulated Geoscape --
The purpose of this project is to replicate the Geoscape from MicroProse' 1994 game XCOM: UFO Defense, an isospheric representation of Earth
created using no modern 3D resources.

Enter //cmake --build . --config Debug ; if ($?) { .\Debug\geoscape.exe } into your Powershell console to run from command line.
